# The Caterist


A full-stack web application developed with C# ASP.NET Core MVC, Entity Framework Core, and MS SQL Server. Designed to manage event dining workflows, featuring structured backend business logic, relational database modeling, and role-based operational flows.


Database Installation Instructions:
Database scripts are included in the folder for the smooth operation of the project. To get the database back on its feet:

The "database_build_script" in the project main directory.you can run the "sql" file through SQL Server.

Or you can enable the automatic installation of the database by running the "dotnet ef database update" command on the VS Code terminal.
